Purser is mostly headless. Your AI agent handles day-to-day work through MCP
or REST; the web UI provides administrative controls. Purser stores your
financial records, performs calculations and supplies context to your agent.
You choose what to share.

Purser is an AI enablement engine, not an AI. No AI subscription is required.
Optional model integrations for categorization and review are off by default;
see [API-first design](./explanation/api-first/).
